# Nelly Career README

A version-controlled excavation of Nelly Sugu's lived and professional history.

This repository is not primarily a resume. It is a source-of-truth substrate from which resumes, portfolios, case studies, writing, consulting offers, products, and market experiments can be derived.

## Provenance rule

**Raw testimony is primary evidence.**

Material under `source/transcripts/` preserves Nelly's recollection as given. It must not be silently cleaned, corrected, strengthened, or rewritten. Apparent errors, uncertain dates, terminology, and later corrections belong in downstream notes/evidence records while the source remains intact.

```
Raw testimony -> Checkpoint -> Evidence/Artifacts -> Capabilities -> Markets -> Experiments -> Outputs
```

Interpretation never overwrites source.

## Repository map

- `source/transcripts/` — immutable primary-source testimony
- `checkpoints/` — bounded chronological syntheses
- `evidence/` — claims, artifacts, verification status, and provenance
- `capabilities/` — capability registry and detailed capability READMEs
- `markets/` — mappings from capabilities to buyers/problems/value
- `experiments/` — small tests of economic demand
- `outputs/` — derivative renderings: resume, LinkedIn, portfolio, book, offers

## Working principle

**Excavate once. Preserve provenance. Render many times.**
